title: 0.004 Tango and the decimals
---
Like everything in the world of interpersonal somatics, Tango has the [[0.002 benefits-of-interactive-somatics-to-the-raiment|salutary benefits]] of raiment strengthening (stretchiness, magnetism, luster, etc.) for all parts of the raiment, cloak to tenderest inner tendres. And it increases the likelihood of [[0.015 raiment-pluming|pluming]] and [[0.003 fiat-human-partnerships|landing a fiat]], a jackpot for your raiment. 

But one of the most powerful things about the tango system is that when it is running smoothly it has a lot better security than the thinking system does. It provides the user with the capacity to identify and (with some effort) alchemically transmute certain toxic substances, including Detrivore, Flying Decimals, and other fell schemes and viruses. This is a radical benefit, and it’s something thinking is very bad at. In fact, thinking actually oftentimes feeds those bugs. 

In fact, some Guild leaders go so far as to say that the very purpose of tango, and the core reason for installing it and maintaining it (a non-negligible investment), is exactly this highly secure environment.
