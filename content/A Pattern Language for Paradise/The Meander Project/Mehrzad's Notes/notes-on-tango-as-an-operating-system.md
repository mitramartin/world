title: Notes on tango as an operating system
author: Mehrzad Esfandiari
---
Conventional operating system: “thinking.” Throughout Alexandria it provides the main go-to interface between bodies and possibilities. 

But as an OS “thinking” is rather obtuse and anemic. 

- Limited inputs and limited outputs
- Can’t access raiment-blood, or anything that pulses through raiment, as an input
- Can only output in the form of words and sentences. Thus so many flat-footed/ ham-handed/lackluster outputs

As D. Quattrochhi writes: “Tango is an operating system which was lovingly hand-coded by raiment-seers in Argentina around a hundred years ago, plus or minus. Therefore it has the capability to accept many more kinds of inputs, not only from one’s own raiment but also from that of others. As a raiment-native system, its outputs are also more multidimensional. The tango has many regional manifestations (West Coast tango, sockfoot tango, metta tango, sun tango, ntango, _tango, xango, and many many others) but they all form part of the same underlying kernel of unconditional all-inclusive embodied finely-discerning love.”

Benefits of tango OS: 

- Better security than the thinking system
- Provides the user with the capacity to identify, alchemically transmute certain toxic substances, including Detrivore, Flying Decimals, other fell schemes and viruses. 
- A radical benefit. It’s something thinking is very bad at. (Thinking actually oftentimes feeds those bugs.)  

Qq: Could we say that the very purpose of tango, and core reason for installing it and maintaining it, is exactly this highly secure environment?
